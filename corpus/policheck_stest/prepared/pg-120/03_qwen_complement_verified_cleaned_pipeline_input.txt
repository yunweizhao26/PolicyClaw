Dungeon Cards Privacy Policy
The app "Dungeon Cards" by 717 pixels
DOES NOT
collect any sort of personal data about players. We do not collect info about names, emails, contacts, phone ID, phone number, user location.
The app
DOES
collect an anonymous data about player actions in the game (what menu items were clicked, what dungeons were finished and with what scores, etc.) We don't (and can not) connect these data to any particular person and we see just aggregate numbers (like, "yesterday 300 players have finished dungeon 3 and 100 players have finished dungeon 4"). We use the standard Unity Statistics module to collect data and Unity web interface to analyze it. This data is used exclusively by us the developers to make an app experience better (tune the game balance, get rid of some unused menu items).
The app permission to read and write data on the device storage is used
ONLY
to read/write game save files (we use two save files -- the main file and a backup file if the main file gets corrupted).
The app permission to access the Internet is used to send data to Google Play Games leaderboard service and to send anonymous stats about game usage to Unity servers. Potentially it will be used to send and load save files to/from Google servers and to load the ads from the Internet.
