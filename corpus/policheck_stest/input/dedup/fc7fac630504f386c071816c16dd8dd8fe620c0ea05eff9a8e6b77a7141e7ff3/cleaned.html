9. Permissions used by Brightest LED Flashlight

1. Camera permission

Camera permission is only required for the flashlight feature in Brightest LED Flashlight. It needs access to your device’s camera flashlight and does not take photos and videos for any purposes.

2. Write Settings

This Permission allows users to set call flash for contacts

3. Full network access and receive data from Internet

This permission allows Brightest LED Flashlight to access the device’s network for functions including accessing app classification labels.

4. View network connection

This permission is used in Brightest LED Flashlight settings in order to view network connections.
5. Prevent phone from sleeping

The only purpose using this permission is to prevent the phone from going to sleep when you are playing videos in full screen mode. It is not used for any other purposes.

6. Control Flashlight

This permission allows Brightest LED Flashlight to turn ON/OFF your device’s camera flashlight.

7. Change system display settings

This permission is used to light screen when you turn on the flashlight which is occupied.
