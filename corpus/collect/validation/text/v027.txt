Privacy Policy for Device Info
Effective Date: Aug 17, 2025
Last Updated: Aug 17, 2025
1. Introduction
This Privacy Policy describes how Device Info ("we," "us," or "our") collects, uses, and protects information when you use our mobile application (the "App"). We are committed to protecting your privacy and ensuring transparency about our data practices.
2. Information We Collect
2.1 Device Information
Our app accesses the following device information to provide its core functionality:
Hardware Information: Processor details, RAM specifications, storage capacity, display properties, camera specifications, sensor information
System Information: Operating system version, device model, manufacturer details, build information, phone state information
Performance Data: CPU usage, memory usage, battery status, temperature readings
Network Information: Wi-Fi connection details, network signal strength, IP address, network connectivity status
Location Information: Approximate location data (used only for network-based location services and Wi-Fi network identification)
Display Information: Screen resolution, density, refresh rate, color depth
2.2 Information We Do NOT Collect
Personal identification information (name, email, phone number)
Precise location tracking or GPS history
Contacts, messages, or call history
Photos, videos, or media files
Browsing history or app usage data from other apps
Passwords or authentication credentials
Financial or payment information
Note on Location: We may access approximate location information solely for network identification and Wi-Fi analysis features. This data is not stored or transmitted outside your device.
3. How We Use Information
The information accessed by our app is used solely for:
Display Purposes: Showing device specifications and system information within the app interface
Performance Monitoring: Providing real-time system performance metrics
Network Analysis: Displaying Wi-Fi network information and connectivity details
Location Services: Approximate location for network-based services (Wi-Fi network identification)
4. Data Storage and Security
4.1 Data Processing
Most device information is processed and displayed locally on your device
Network connectivity may be used for enhanced network analysis features
Location data (when accessed) is used only for network identification and is not stored permanently
No personal information is transmitted to external servers without explicit user consent
4.2 Network Usage
Internet permission is used for network diagnostics and speed testing features
No personal or sensitive device information is transmitted over the internet
Any network communications are limited to diagnostic functions only
4.2 Security Measures
The app uses standard Android/iOS security protocols
No network permissions for data transmission
Information remains within your device's secure environment
5. Data Sharing and Third Parties
We maintain strict data privacy practices regarding third parties:
No personal data sharing: Device specifications and system information are not shared with third parties
Network diagnostics only: Internet connectivity is used solely for network testing and analysis features
No advertising networks: No third-party advertising services have access to your information
No analytics tracking: No user behavior or usage analytics are collected or transmitted
Optional features: Any network-based features require explicit user interaction
6. Permissions
Our app requires the following permissions:
Android Permissions:
INTERNET: For network diagnostics, speed testing, and connectivity analysis
ACCESS_WIFI_STATE: To read Wi-Fi connection information and network details
CHANGE_WIFI_STATE: To enable/disable Wi-Fi for diagnostic purposes (user-initiated only)
ACCESS_NETWORK_STATE: To display network connectivity information and status
ACCESS_FINE_LOCATION: For precise Wi-Fi network identification and location-based network services
ACCESS_COARSE_LOCATION: For approximate location to identify nearby Wi-Fi networks
READ_PHONE_STATE: To access device model, system information, and network operator details
Important: Location permissions are used exclusively for Wi-Fi network identification and network analysis features. No location tracking or storage occurs.
iOS Permissions:
Device information access through standard iOS APIs
Network state information for connectivity details
No special permissions required for basic device information
Note: All permissions are used exclusively for displaying information within the app and providing network diagnostic features. Location permissions are used only for Wi-Fi network identification and are not used for tracking or storing your location.
7. Children's Privacy
Our app does not knowingly collect personal information from children under 13 years of age. The app only accesses technical device information that is not personally identifiable. Parents and guardians should supervise their children's use of mobile applications.
8. Changes to Device Information
Since our app only reads and displays existing device information without storing it:
You can uninstall the app at any time to stop access to device information
No persistent data remains after app removal
App permissions can be revoked through device settings
9. International Users
Our app functions entirely offline and locally on your device. No data crosses international boundaries as no information is transmitted from your device.
