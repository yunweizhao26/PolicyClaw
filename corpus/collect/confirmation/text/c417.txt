iHealth is an educational-grade application, although fully functional and dynamic. It was build using appinventor to demonstrate the functionality offered by appinventor and is a part of a complete tutorial blog post on how to build applications of this kind. The app uses android.permission.READ_PHONE_STATE, which is used to read phone sensor data and to report to the user. In addition it is capable of sharing content ONLY per user s choice by presenting a complete sharing menu. No user data or any other sensitive data are being recorded, shared, stored, or by any means being transferred to a third party by the developer of this app.
