Introduction
FridgeFeast ("we," "our," or "us") respects and protects the privacy of our users ("you," "your," "user"). This Privacy Policy details how we collect, use, disclose, and safeguard your information when you use our mobile application.
Information We Collect
Personal Information
We collect:
- Email addresses for account creation and authentication
- User-provided profile information (optional)
- Profile photos (optional)
- Food allergy information
- Cooking preferences
- Device information and unique identifiers
- Usage data and interaction patterns
- IP addresses and geolocation data
User-Generated Content
We collect:
- Saved recipes
- Favorite recipes
- Custom recipe modifications
- User feedback and ratings
Technical Data
We automatically collect:
- Device type and model
- Operating system version
- App version
- Time zone settings
- Mobile network information
- Crash reports
- Performance data
- Session duration
- Feature usage statistics
How We Use Your Information
Core Functionality
- Account creation and management
- Recipe generation and personalization
- Saving user preferences and favorites
- Authentication and security
- App functionality and performance
Service Improvement
- Analyzing user behavior and patterns
- Improving recipe generation algorithms
- Enhancing user experience
- Debugging and technical improvements
- Feature development and optimization
Data Storage and Security
Storage Methods
- Firebase Authentication for user credentials
- Firebase Cloud Storage for profile images
- Firebase Firestore for user preferences and recipes
- Local device storage for temporary data
- Encrypted transmission using industry-standard protocols
Security Measures
- End-to-end encryption for data transmission
- Secure user authentication
- Regular security audits
- Access controls and monitoring
- Automated threat detection
- Regular backup procedures
Third-Party Services
Service Providers
We use:
- Firebase (Google LLC) for authentication and storage
- Anthropic's Claude API for recipe generation
- Analytics providers for app performance monitoring
- Crash reporting services
Data Sharing
We share data with third parties only:
- When necessary for app functionality
- With your explicit consent
- As required by law
- In anonymized, aggregated form for analytics
Your Rights and Controls
User Rights
You can:
- Access your personal data
- Correct inaccurate information
- Delete your account and associated data
- Export your data
- Opt out of non-essential data collection
- Update your preferences
- Withdraw consent for optional features
Account Deletion
When you delete your account:
- All personal information is permanently removed
- Saved recipes are deleted
- Profile photos are removed from storage
- Usage data is anonymized
- Some information may be retained for legal purposes
Children's Privacy

- Parents/guardians can request data deletion
- Age verification may be required
- Special protections for users 13-18
International Data Transfer
- Data may be processed in different countries
- We ensure appropriate safeguards
- We comply with international data protection laws
- Cross-border transfer protocols are in place
Changes to Privacy Policy

- Users will be notified of significant changes
